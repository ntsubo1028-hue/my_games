記憶力ゲームの遊び方

🎮 ゲームの目的

表になったカードの絵柄と位置を素早く暗記し、伏せられた後にすべてのペアを間違えずに当てるタイムアタックゲームです。できるだけ短い時間で暗記してハイスコアを目指しましょう！

🎯 基本ルール

  1. 難易度選択: レベル1（4枚）〜 レベル4（16枚）から遊ぶレベルを選びます。
  2. 暗記タイム（スタート）: 「▶ 開始」ボタンを押すとタイマーが動き出し、すべてのカードが開きます。配置をしっかりと暗記しましょう。
  3. 回答タイム: 覚え終わったら「🧠 覚えた！」ボタンを押します。カードがすべて裏返り、回答スタートです。
  4. ペア当て: 暗記した位置を思い出して、同じ絵柄のペアを順にタップしてめくっていきます。
  5. 一発アウト: 1度でもペアを間違えると即ゲームオーバーになります！慎重に回答しましょう。

📱 操作方法

  • 「▶ 開始」ボタン: カードを開いて暗記タイマーを開始します。
  • 「🧠 覚えた！」ボタン: 暗記を終了してタイマーを止め、回答を開始します。
  • カードをタップ: めくりたいカードをタップ（またはクリック）します。

🏆 ランキングと評価

間違えずにすべてのペアを当てるとクリアとなり、暗記にかかった時間が記録されます。
オンラインランキングにはレベルごとに登録され、暗記タイムが短ければ短いほど上位になります！
